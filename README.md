The app fetches public listing data from the Warframe Market API (warframe.market). Requests contain no personal
information.

## Local storage

Settings, filters and cached data are stored on your device. This data:

- Is never sent to any server
- Is never shared with third parties
- Is removed when you uninstall the app

## Notifications

If enabled, notifications are scheduled on your device. No notification tokens or identifiers are sent to any server.

## Third parties

No data is collected from anyone, including children under 13.
